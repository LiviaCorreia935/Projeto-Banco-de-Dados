# Projetos de Banco de Dados

Este repositório contém exercícios e projetos desenvolvidos para prática e aprendizado de **Banco de Dados**, com foco em modelagem relacional, criação de estruturas de dados e consultas SQL.

Os projetos simulam cenários práticos utilizados em sistemas reais, permitindo aplicar conceitos fundamentais de banco de dados.

## Conteúdos abordados

- Modelagem relacional de dados
- Criação e manipulação de tabelas
- Consultas SQL (`SELECT`, `JOIN`, `WHERE`, `GROUP BY`)
- Inserção, atualização e exclusão de registros (`INSERT`, `UPDATE`, `DELETE`)
- Projetos práticos de banco de dados

## Tecnologias Utilizadas

- SQL
- MySQL
- PostgreSQL
- SQL Server

## Conceitos aplicados

- Modelagem de banco de dados relacional
- Diagramas Entidade-Relacionamento (ER)
- Normalização de dados
- Estruturação de tabelas e relacionamentos

## Objetivo

Praticar e consolidar conhecimentos em **modelagem de dados, linguagem SQL e manipulação de bancos de dados relacionais**, aplicando conceitos utilizados no desenvolvimento de sistemas.
